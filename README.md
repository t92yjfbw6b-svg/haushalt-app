# Haushalt-App

Web-App fürs iPhone: Ausgaben schnell eintragen, Restbudget pro Kategorie sehen.
Die Daten liegen nur in der eigenen Google-Tabelle; die Brücke dorthin ist `apps-script/Code.gs`.

- Einrichten: siehe [ANLEITUNG.md](ANLEITUNG.md)
- Ausprobieren ohne Tabelle: Seite mit `#demo` am Ende öffnen.
